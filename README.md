# Mentor X

**Mentor X** is a fully automated mentorship and collaboration platform connecting students with mentors and peers. It enables AI-driven counselling, guidance, and task assistance using multiple intelligent bots, reducing manual effort and saving time.

---

## 🛠 Key Features

- Automated mentorship and collaboration platform for students and mentors  
- AI-driven counselling and task guidance  
- Voice interactions and workflows powered by **ElevenLabs** and **n8n**  

---

## 💻 Tech Stack

**Frontend & Backend:** React.js, Node.js, Express.js  
**AI & Automation:** ElevenLabs, n8n, Python  
**Database:** MongoDB  
**Authentication:** Clerk
